# Image and System Analysis (ISA)

This repository hosts the hands-on Jupyter Notebook lab materials for the **Image and System Analysis** course, taught at the **Division of Medical Radiation Physics, Stockholm University**.

The materials are designed specifically for students enrolled in the course, but are freely available to anyone interested in learning the fundamental concepts of digital image processing, with an introduction to medical images.

## Course Structure

Each lab is designed to follow the pace of the corresponding lecture. Accordingly, the theoretical lecture materials are complemented by hands-on lab sessions, where students implement, visualize, and experiment with the same concepts covered in class.
